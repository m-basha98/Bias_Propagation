# Following the Bias: Propagation of Bias Across the Software Development Stages in AI-Generated Code

This repository contains the code, data, generated outputs, and statistical analyses for the study.

## Repository Structure

### Folders

Begin by unzipping Output and Bias Reports folders. 

- **`Output/`** — Contains the code generated by **Qwen** and **Gemini** for all stages of the software development workflow.
- **`Bias Reports/`** — Contains the bias audit reports generated for each output file by both models.
- **`Data/`** — Contains the bias-injected requirements corresponding to the 91 experimental variations.
- **`Metrics/`** — Contains the processed metrics used for the statistical analyses.
- **`Tables/`** — Contains the descriptive and inferential statistical results reported in the study.

### Scripts

- **`system_prompt5.md`** — Contains the in-context learning (ICL) prompt used with Gemini to generate the bias audit reports.
- **`calculate_bias_metrics.py`** — Performs preprocessing and calculates the bias metrics required for the subsequent statistical analyses.
- **`calculate_stats.py`** — Performs the statistical analyses and generates the corresponding results.
- **`run_experiment.py`** — Executes the first stage of the study by generating code artifacts for all experimental conditions and workflow stages.
- **`bias_auditing.py`** — Executes the bias-auditing stage using the ICL prompt to generate bias reports for the generated code artifacts.

## Running the Experiment

To reproduce the experiment, first provide your own **Gemini API key** in the appropriate configuration or environment variable used by the scripts.

The experiment proceeds in the following stages:

1. **Code Generation:** Run `run_experiment.py` to generate code artifacts across all experimental conditions and workflow stages.
2. **Bias Auditing:** Run `bias_auditing.py` to analyze the generated artifacts and produce the corresponding bias reports.
3. **Metric Calculation:** Run `calculate_bias_metrics.py` to preprocess the results and calculate the required bias metrics.
4. **Statistical Analysis:** Run `calculate_stats.py` to perform the statistical analyses and generate the corresponding results.
